# electron-components

Componentes de layout usados pelos aplicativos Electron. O pacote exporta a fonte TypeScript, e o Vite de cada aplicativo gera o bundle.

A descrição de cada componente, as props e um exemplo de uso estão em [docs/COMPONENTES.md](docs/COMPONENTES.md).

React é dependência do aplicativo (`peerDependency`). Este pacote não inclui Electron, IPC nem scripts de build.
